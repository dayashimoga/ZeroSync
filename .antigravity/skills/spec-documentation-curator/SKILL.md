# Specification & Documentation Curator Skill
1. **Spec-Driven Alignment:** Keep `docs/ARCHITECTURE.md`, `docs/OPTICAL_PROTOCOL_SPEC.md`, `docs/SECURITY_MODEL.md`, and `README.md` synchronized with every newly wired UI workspace and domain capability.
2. **Traceability:** Document every public entity, service, and BLoC with clear DartDoc comments explaining security invariants, thread/isolate boundaries, and lifecycle disposal rules.
3. **Additive Preservation:** Never delete historical decision logs, engineering contracts, or stage completion records.
